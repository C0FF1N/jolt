# baseline

The **upstream Browser MCP server source, unmodified**, kept only as the reference that Jolt's benchmarks
(`bench/`) and compatibility tests are measured against. It is not part of Jolt and is not published.

- Upstream project: <https://github.com/browsermcp/mcp> (Apache-2.0, see `LICENSE` in this folder)
- Upstream's README and banner image were removed from this copy (they are the upstream project's branding); the
  source files are unchanged.
- Attribution and the exact relationship to Jolt: see the repository's `NOTICE`.
